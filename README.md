# An Invitation to Analytic Combinatorics - Lecture Series Code

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/smelczer/MPI26-Code/HEAD)

This repository contains Jupyter notebooks with SageMath code for lectures delivered at the Max Planck Institute for the Mathematical Sciences from June 9 – June 11, 2026.

The notebooks can be run in your browser with nothing to install using [Binder](https://mybinder.org/v2/gh/smelczer/MPI26-Code/HEAD) (launching may take a few minutes). The Binder environment comes with the
[`sage_acsv`](https://github.com/ACSVMath/sage_acsv),
[`ore_algebra`](https://github.com/mkauers/ore_algebra), and
[`sage_periods`](https://github.com/ACSVMath/sage_periods) packages preinstalled.

See the [lecture series website](https://melczer.ca/MPI26/) for further information.
